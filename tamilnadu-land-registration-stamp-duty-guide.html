TNREGINET Guideline Value என்பது தமிழ்நாடு பதிவுத் துறை நிர்ணயித்த குறைந்தபட்ச சொத்து மதிப்பாகும். பொதுவான விற்பனைப் பத்திரங்களில் (Sale / Conveyance Deed) முத்திரைக் கட்டணம் (Stamp Duty) 7% மற்றும் பதிவுக் கட்டணம் (Registration Fee) 4% ஆகிய சதவீத அடிப்படையில் கட்டணங்கள் கணக்கிடப்படுகின்றன (ஆவண வகை மற்றும் அரசின் சமீபத்திய அறிவிப்புகளுக்கு ஏற்ப மாறுபடலாம்). ஒப்பந்த மதிப்பு மற்றும் வழிகாட்டு மதிப்பு ஆகிய இரண்டில் எது அதிகமோ அதன் அடிப்படையில் கட்டணம் கணக்கிடப்படும்.

💡 முக்கிய கட்டண விதிகள் மற்றும் சதவீதங்கள் (Key Registry Rules 2026):

  • TNREGINET Guideline Value விதி: ஒப்பந்த மதிப்பு மற்றும் அரசு வழிகாட்டு மதிப்பு இரண்டில் எது அதிகமோ (Higher Value) அதன் அடிப்படையில் கட்டணம் கணக்கிடப்படும்.
  • முத்திரைக் கட்டணம் (Stamp Duty): பொதுவான விற்பனைப் பத்திரங்களுக்கு 7%.
  • பதிவுக் கட்டணம் (Registration Fee): பொதுவான விற்பனைப் பத்திரங்களுக்கு 4% (மொத்தம் சுமார் 11% அடிப்படைக் கட்டணம்).
  • குறிப்பு: ஆவண வகை (Gift, Partition, Settlement, Sale) மற்றும் சமீபத்திய அரசு அறிவிப்புகளுக்கு ஏற்ப கட்டண சதவீதங்கள் மாறுபடலாம்.

பதிவுக் கட்டணம் கணக்கிடும் சூத்திரம் (Registry Calculation Formula)

TNREGINET வழிகாட்டு மதிப்பு மற்றும் சதவீதங்களின் அடிப்படையில் கட்டணத்தைக் கணக்கிடும் எளிய சூத்திரங்கள்:

முக்கிய சூத்திரம் (Core Formula):
Chargeable Value = Max(Agreement Value, TNREGINET Guideline Value)
Stamp Duty = Chargeable Value × (Stamp Duty % ÷ 100)
Registration Fee = Chargeable Value × (Registration Fee % ÷ 100)
Total Registry Cost = Stamp Duty + Registration Fee
